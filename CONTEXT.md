# Macofu

Macofu means “Make coding fun again.” It explores full-stack software engineering through hands-on learning modules.

## Language

**Macofu**:
A learning product for full-stack software engineering, built around making coding fun through hands-on challenges.
_Avoid_: Backend-only learning product, interview-prep platform

**Module**:
A focused, playable learning experience within Macofu. A module can contain multiple lesson parts and investigations; the order dispatch factory is the first module.
_Avoid_: Calling each part a separate module

**Investigation**:
A learning challenge within a Macofu module where the learner examines a running system and uses evidence to explain its behavior.
_Avoid_: Quiz, tutorial
